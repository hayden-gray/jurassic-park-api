# Jurassic Park API

JSON REST API for tracking the park's cages and the dinosaurs in them. Built for the
PrizePicks Ruby on Rails back-end assessment.

**Status:** work in progress. This commit is a blank Rails API app with RSpec and FactoryBot.

## Stack

- Ruby 3.4.4, Rails 8.1 (API mode)
- PostgreSQL
- RSpec + FactoryBot

## Setup

```sh
bundle install
bin/rails db:create db:migrate
bundle exec rspec
bin/rails server
```
